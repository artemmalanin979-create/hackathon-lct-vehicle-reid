# Задание: есть ли в кадрах сигнал «камера → место» — только измерение

Работай молча. Один финальный отчёт, `journal.md` и `REPORT.md` по ходу. Своя папка
локально и `~/lct-reid/jobs/job_47/` на узле.

## Зачем

Предложение Артёма: сверять кандидатов по контексту точки съёмки (маршрут, физическая
достижимость). В данных этого нет: в `val_query.csv`/`val_gallery.csv` только
`image_id, x, y, w, h, vehicle_id, camera_id` — ни времени, ни координат. Без штампа
времени «доехать нельзя» не работает.

Что проверить можно: **носят ли сами кадры сигнал о месте**. Если у каждой камеры стабильный
фон (точка съёмки неподвижна), то по фону можно кластеризовать камеры в локации и мерить
совместимость кандидата с точкой — без каких-либо метаданных, из пикселей.

Это измерение, а не фича. Не предлагай «вкрутить в решение», пока не измерено.

## Что сделать

1. **Стабильность фона у камеры.** Для 96 камер возьми по несколько кадров каждой
   (из `~/lct-reid/data/images/`, там 1860 валидационных кадров; `camera_id` из CSV
   сплита). Убери автомобиль по рамке (x,y,w,h), сравни фоны: насколько кадры одной камеры
   похожи друг на друга против чужих камер. Метрика — на выбор: гистограммы, SSIM на
   фоне, признаки OSNet по кадру без объекта. Число: точность отнесения кадра к своей
   камере по одному фону (top-1, top-5 из 96).

2. **Кластеры камер.** Кластеризуй камеры по фону. Сколько получилось, какие камеры
   сливаются. Это и есть «места».

3. **Есть ли от этого польза для метрики — честно.** Протокол уже исключает
   same-camera пары из оценки. Значит сигнал может действовать только как приоритет между
   разными камерами одной локации. Посчитай на векторах финальной конфигурации
   (job_45b, `~/lct-reid/jobs/job_45/out/s02_perquery.npz` и таблица): сколько ошибок
   top-1 — это кандидаты с «несовместимой» локацией, и сколько верных ответов при этом
   оказались бы задеты. Отдельно: если убрать/штрафовать кандидатов из того же
   фон-кластера, что и запрос, — что станет с mAP. Если ошибок таких почти нет — скажи
   прямо, что механизму нечего ловить.

4. **Вывод:** есть ли в данных сигнал камера→место, можно ли из него построить
   «совместимость точек», и стоит ли она того при нашем протоколе.

## Правила

- Только наши кадры и наш контур. Ничего не выдумывать: чего не измерил — так и пиши.
- Не предлагать признаки ГРЗ.

## Что вернуть

1. Точность отнесения кадра к камере по фону (top-1/top-5), таблица по камерам.
2. Число и состав кластеров камер.
3. Сколько ошибок top-1 — «несовместимая» локация; эффект штрафа на mAP.
4. Вердикт: есть ли сигнал и есть ли польза.
