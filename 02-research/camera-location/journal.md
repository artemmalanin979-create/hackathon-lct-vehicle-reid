# job_47 — журнал: сигнал «камера → место» из пикселей фона

## Постановка (BRIEF)
Проверить измерением, несут ли сами кадры сигнал о месте съёмки:
1. стабильность фона у камеры + точность отнесения кадра к камере по фону (top-1/top-5);
2. кластеры камер по фону = «места»;
3. честная оценка пользы для метрики на финальной конфигурации (job_45b, d1_w1.0);
4. вердикт.

## Окружение / данные (проверено)
- `ssh worker-vm` работает; считаем только там. Квота 4 ядра/16 ГБ на две сессии → долгие прогоны через nohup.
- Валидация: `repo/04-solution/split/files/val_{query,gallery}.csv` — 1110 + 750 = 1860 кадров.
  Уникальных камер в валидации: **90** (не 96 — в брифе 96, фактически в сплите 90; замеряем по 90).
  Кадров/камера: query min 1, медиана 8, max 129.
- Кадры: `~/lct-reid/data/images/<image_id>.jpg`, все 1920×1080. CSV: image_id,x,y,w,h,vehicle_id,camera_id,has_mate.
- Транспорт в валидации: 369 vehicle_id, из них 357 есть более чем в одной камере → мейты почти всегда кросс-камерные.
- Финальная конфигурация (job_45, out/s02_configs.json): **d1_w1.0** = Lw_ens(l2(OSNet+ain_v2)), KR(6,3,0.3),
  market-исключение камеры: mAP=0.7621, R1=0.7175, valid=832 известных запросов.
- Контур метрик: `repo/04-solution/eval/reid_metrics.py` (evaluate, camera_policy="market", refusal presence).
- На узле venv job_45b: numpy 2.4.6, onnxruntime 1.30.0, pillow; cv2/sklearn/scipy НЕТ → всё на numpy+PIL.
- Веса: `~/lct-reid/weights/ain_v{1,2}_s*.onnx`, вход 208×208 RGB 0..255 NCHW, нормировка внутри графа.
- Прежняя работа про камеры (training/attempt-2/cam_penalty.py, camnet) — про камерный эмбеддинг из ReID-ветки,
  НЕ про фон из пикселей. Это задание — про пиксельный фон, механизм другой.

## План скриптов (~/lct-reid/jobs/job_47/)
- scripts/s10_bg_features.py — маскирование bbox, дескрипторы фона: thumbnail-RGB, HSV-гистограмма, эмбеддинг ain_v2 по замаскированному кадру.
- scripts/s11_cam_id.py — leave-one-out отнесение кадра к камере по фону (top-1/top-5), same-vs-diff контраст, SSIM-контраст.
- scripts/s12_cluster.py — кластеризация камер (агломеративная, косинус), устойчивость по трём дескрипторам.
- scripts/s13_effect.py — эффект кластеров на метрику: диагностика top-1 ошибок, штраф same-cluster / фильтр cross-cluster, контроль на случайных кластерах.
