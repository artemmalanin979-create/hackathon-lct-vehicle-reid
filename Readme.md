# ЛЦТ 2026 — цифровой признак транспортного средства

Задача №7 «Фалькон Тех», команда 33. Сервис принимает изображение и bbox,
формирует 512-мерный признак автомобиля и возвращает похожие объекты либо отказ.
Сдаваемая конфигурация — **d1_j48**: две модели OSNet-AIN, whitening и
пакетное k-reciprocal переранжирование; HTTP API использует косинусный поиск.

Локальный кандидат 25.09: рабочий интерфейс ведёт от разрешённого демо-кадра
или собственного JPEG/PNG через bbox и настоящий поиск к сравнению, отказу,
разбору и выгрузке. Обученный в отдельном эксперименте student снизил CPU p95,
но потерял mAP; релизная модель остаётся d1_j48. Подробности и измерения —
[§13](SOLUTION.md#continuation-20260925).

Команда из §4 собирает образ и запускает API, Qdrant и загрузчик галереи.
Ей предшествуют установка Docker/Compose, получение данных и импорт базовых
образов для офлайн-работы. Запуск подтверждён прогоном и на Podman, и на Docker Engine 29.7.2
с Compose V2 2.40.3 ([отчёт](04-solution/audit/docker-path/README.md)). Для некоторых внешних обучающих данных и исторических
окружений точные версии неизвестны — эти пробелы перечислены, полное
соответствие требованиям воспроизводимости не заявляется.
