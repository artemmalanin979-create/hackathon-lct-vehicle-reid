# Поиск автомобиля по кадру

**ЛЦТ 2026 · задача №7 «Фалькон Тех» · команда 33 «ПРОСВЕТ»**

Выделите автомобиль на снимке — сервис найдёт визуально похожие объекты в
галерее, покажет пару кадров для проверки и откажет, если близость ниже порога.
Номерной знак не используется как входной идентификатор. Модель получает весь
кроп автомобиля, поэтому полную независимость от области номера мы не заявляем.

## Что можно проверить

1. Открыть демо-кадр или загрузить JPEG/PNG и уточнить рамку автомобиля.
2. Выполнить настоящий поиск по галерее из 750 объектов, сравнить кадры и
   посмотреть разбор. При низкой близости сервис показывает отказ.
3. Скачать CSV или JSON именно для текущего результата. Интерфейс работает в
   светлой и тёмной темах, в том числе на узком экране.

Публичный сервис использует косинусный поиск. Сдаваемый пакетный расчёт применяет
k-reciprocal переранжирование; результаты этих режимов нельзя смешивать.

## Модель и проверенные результаты

Сдаваемая **d1_j48** объединяет OSNet-AIN и дообученную нами `combined_v1`:
нормировка признаков → усреднение → whitening → нормировка. Выход — 512 чисел.
В пакетном режиме к ранжированию добавляется k-reciprocal. Точная схема,
препроцессинг и пороги приведены в [SOLUTION.md](SOLUTION.md#methods).

![Схема получения признака и двух режимов поиска](05-presentation/assets/pipeline.svg)

| Локальная проверка | mAP | Rank-1 |
|---|---:|---:|
| Пакетная d1_j48 + k-reciprocal | 0,7741 | 0,7308 |
| Та же модель, cosine (режим поиска API) | 0,7316 | 0,6851 |

Обе строки получены офлайн-оценщиком, а не HTTP-тестом. Протокол: 1110 query ×
750 gallery; у 832 запросов есть допустимая пара,
совпадения одной камеры исключены. Здесь mAP рассчитан по запросам с допустимой
парой. Это **не результат закрытого теста организаторов**; официальный скрипт и
распределение его данных нам неизвестны. Подробные метрики, оценка отказа и
ограничения — в [§6 SOLUTION.md](SOLUTION.md#validation-metrics).

Мы также обучили отдельное image→512D ядро. Оно быстрее в измеренной границе
«подготовленный тензор → дескриптор», но после дообучения дало KR mAP 0,3275;
комбинация с релизом — 0,7626. Поэтому эксперимент сохранён
[отдельно](04-solution/training/owncore-distill-20260926/REPORT.md), а релизная
модель не подменена неподтверждённым улучшением.

## Повторить решение

Это входной файл **`Readme.md` по ТЗ §12**. Подробные команды и условия находятся
в [SOLUTION.md](SOLUTION.md). После установки Docker и Compose, получения
разрешённого комплекта данных и импорта офлайн-образов по
[§3](SOLUTION.md#build-install) сборка и запуск выполняются командой из
[§4](SOLUTION.md#one-command):

```bash
docker compose -f 04-solution/service/docker-compose.yml up --build -d --pull never
```

Запуск поднимает API, Qdrant и однократный загрузчик галереи. Поиск становится
доступен после окончания загрузки; до этого ответ `409` ожидаем. Две ONNX-модели,
whitening, wheels и необходимые офлайн-образы входят в комплект. Данные
организатора передаются разрешённым способом отдельно от Git.
