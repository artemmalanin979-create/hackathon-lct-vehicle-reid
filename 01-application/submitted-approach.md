## Уникальность идеи

Мы формируем не один «глобальный» вектор внешности, а составной и объяснимый цифровой
признак из трёх слоёв:

1. глобальный эмбеддинг внешнего вида (deep metric learning, устойчивый к смене ракурса,
   освещения, частичному перекрытию);
2. структурированный вектор атрибутов — тип кузова, марка/модель, цвет, геометрия
   (мультизадачные головы классификации);
3. локальные «особые приметы» — повреждения, наклейки, диски, рейлинги, тонировка
   (отдельные детекторы).

Сопоставление — не «чёрный ящик»: сервис показывает, **почему** два кадра отнесены к одному
авто (совпавшие приметы), что важно для контроля нарушений и доказуемости.

Отдельный механизм — **«мост к госномеру»**: если для части прошлых событий номер был
известен, идентичность переносится по эмбеддингу на кадры без читаемого номера, формируя
список кандидатов на возможного нарушителя.

## Планируемый результат

Программный сервис (API + демо-интерфейс):

- вход — кадр/кроп ТС → выход — цифровой признак (эмбеддинг + атрибуты);
- поиск по базе и выдача ранжированных кандидатов с оценкой похожести и подсветкой
  совпавших признаков;
- привязка к ранее известному госномеру при наличии совпадения в истории;
- пакетный режим — кластеризация потока событий в группы «один автомобиль».

Качество подтверждаем детерминированно на отложенной выборке: Rank-1/Rank-5, mAP
(CMC-кривая), устойчивость к ракурсу/освещению/перекрытию, латентность запроса.
Метрики считаем честно, воспроизводимым прогоном, без подгонки под лидерборд.

## Используемые технологии

- **Детекция и кроп ТС:** YOLO (v8/v11) / RT-DETR.
- **Re-ID-эмбеддинг:** backbone ResNet-IBN / OSNet / TransReID (ViT/Swin), обучение
  triplet loss + ID-loss; атрибуты — мультизадачные головы; пред-обучение на публичных
  Re-ID-датасетах (VeRi-776, VehicleID, VERI-Wild, CityFlow).
- **Векторный поиск:** FAISS / Qdrant (HNSW, косинусная близость), k-reciprocal re-ranking.
- **Бэкенд:** Python (FastAPI) для ML-сервиса, высоконагруженный слой матчинга/индекса
  на Rust; хранение эмбеддингов и метаданных — PostgreSQL + pgvector / Qdrant.
- **Инференс и доставка:** ONNX Runtime / TensorRT, упаковка в Docker; воспроизводимый
  пайплайн обучения и оценки.

**Команда:** менеджер проекта, бэкенд-разработчик, ML-инженер, специалисты по данным.
