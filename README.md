# ЛЦТ 2026 — Задача №7 «Фалькон Тех»: цифровой признак ТС

Международный хакатон **«Лидеры цифровой трансформации 2026»**, трек **Транспорт**.
Постановщик — **ООО «СТРИТ ФАЛКОН»** (Фалькон Тех).

> **Сервис формирования цифрового признака транспортного средства для сопоставления
> снимков одного автомобиля из разных локаций без использования государственного номера.**

Классическая задача **Vehicle Re-Identification (Re-ID)** с важной прикладной надстройкой:
результат должен быть не только «поиском похожих», но и **компактным переносимым
дескриптором**, которым городские системы обмениваются между собой.

**Что ТЗ поменяло против наших допущений:**

- детекция не нужна — bbox выданы и на train, и на test;

- метрика зафиксирована: **mAP** основная (45 % оценки), Rank-1/Rank-5 дополнительно,
  плюс F1 и TNR за режим отказа (10 %);
- решение сдаётся вместе с Docker, OpenAPI и веб-клиентом, запускается одной командой
  **без интернета**, суммарный размер весов ≤ 2 ГБ;
- оценку организатор получает, **запуская наш код на закрытом тесте** — значит пайплайн
  обязан принимать произвольный тестовый набор.

## ⚠️ Главный технический риск

Re-ID-метрику здесь **тривиально завысить самому себе** — соседние кадры одной проезд-сессии,
утечка камеры между train и test, совпадение по фону вместо машины. Модель с mAP 0.95 на
плохом сплите может дать 0.3 на реальных разных локациях, и мы узнаем об этом от жюри,
а не от себя. Поэтому схема валидации собирается первой и правится раньше архитектуры.
