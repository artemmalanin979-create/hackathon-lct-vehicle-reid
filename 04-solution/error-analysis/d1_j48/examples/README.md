# Иллюстрации для слайдов

Все PNG имеют размер 1920×1080. Кадры реальные, по исходным bbox; без генерации,
ретуши или улучшения разрешения. Масштабирование сохраняет пропорции. В примере
дефекта разметки показаны полные кадры и исходные рамки. Иллюстрации выбраны после
разметки из заранее замороженных случайных наборов; статистика по ним не считается.
