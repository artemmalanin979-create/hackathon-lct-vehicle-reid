ракурс 23, однотипный кандидат 20, освещение 10, кроп 5, дефект разметки 5, не знаю 1.
Дополнительно просмотрены случайные исправления, регрессии, ложные принятия и отказы:
всего 128 позиций / 118 разных запросов. Визуальный разметчик — Codex, без второго
независимого человеческого разметчика.

На тех же запросах против исходной OSNet: 104 исправления, 21 добавленная ошибка;
против OSNet+KR: 78 и 22. При действующем пороге: 60 FP и 226 FN режима presence.

Старый разбор, исходники, конфигурация и порог не менялись. Коммитов и push нет.
