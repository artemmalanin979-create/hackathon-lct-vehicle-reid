# Публичный вход команды ПРОСВЕТ

Статический лендинг живёт отдельно от рабочего приложения. Его каталог
раздаётся Caddy как корень сайта; основной путь пользователя ведёт на
/workspace/ того же origin. /api/* и /static/* проксируются к API,
/submission/* обслуживает опубликованный комплект. Все ссылки на
прототип, демо-кадр и документы в HTML относительные. Это позволяет
проверять сайт на https://www.iamcp.ru/ и https://iamcp.ru/ без правки
клиентского кода. Сервис также открыт на https://demo.lct.iamcp.ru/;
лендинг использует маршрут /workspace/ того же origin, поэтому
не зависит от отдельного поддомена.

## Дизайн-замысел

Главная страница ведёт жюри от реального кадра к работающему поиску,
измерениям и материалам решения. Выразительная обложка задаёт ритм; ниже
композиция становится спокойнее и оставляет место для доказательств.

- Фон #0b0e0d, близкая поверхность #161b18, основной текст
  #f2f4ee, вторичный #a9b2aa, линии #414b43, сигнал
  #a8e83c. Сигнал взят из логотипа команды и означает выделенный
  объект либо главное действие, а не произвольное украшение.
- Крупный Montserrat задаёт связь с презентацией; Adwaita Sans читает
  служебный текст; Noto Serif Italic используется только на трёх
  фразах обложки и разделов. Шрифт Noto Serif локально сокращён до
  применённых символов, лицензия рядом с файлом.
- Единственный выразительный приём: исходный кадр проходит через
  типографическую обложку, а точная зелёная рамка указывает на
  автомобиль. Размеры и положение рамки рассчитаны из разрешённого
  примера GET /api/demo, bbox [734, 341, 608, 551] в кадре
  1920×1080.
- После обложки: реальный сценарий поиска, фактический снимок
  рабочего сервиса, раздельные показатели batch KR и HTTP cosine,
  затем ссылки на комплект. Контент не обещает вероятность
  совпадения и не объявляет снимок сервиса нарисованным макетом.

## Локальная проверка

Обычный python3 -m http.server 18072 из этой папки показывает
статическую часть; без reverse proxy демо-кадр ожидаемо недоступен.
Для полной проверки нужен HTTP-origin с маршрутом
/api/demo/street/image. Проверить ширины 390, 768 и 1440 px,
загрузку шрифтов и кадров, отсутствие горизонтального скролла,
контраст/focus, prefers-reduced-motion, все документы и CTA.
Опубликованные PDF/PPTX находятся вне Git; их 200/MIME/хеш
проверяются при развёртывании.
