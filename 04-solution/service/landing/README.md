# Статический вход для жюри

`index.html` — страница `https://lct.iamcp.ru/`. Caddy должен раздавать этот
каталог как корень сайта (`root * /srv/lct/landing`, `file_server`). Папка
`fonts/` и файлы `landing.css`, `landing.js` должны остаться на том же origin.

Ссылки на `/submission/documentation.pdf`, `/submission/presentation.pdf` и
`/submission/presentation.pptx` обслуживает развёртывание; в Git этих файлов
полной презентации нет. До публикации нужно проверить HTTP 200, MIME и
соответствие хешей размещённым файлам. `https://demo.lct.iamcp.ru/` ведёт в
реальный сервис. Обложка берёт разрешённый демонстрационный кадр из его API,
поэтому исходные данные не копируются в Git; при недоступности API появляется
текстовая заглушка.

Локальная проверка статической страницы: `python3 -m http.server 18072` из
этой папки и открыть `http://127.0.0.1:18072/`. Пока публичный API не поднят,
кадр покажет заглушку; это ожидаемо.
