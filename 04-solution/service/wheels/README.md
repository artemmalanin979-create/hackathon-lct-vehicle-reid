# Колёса зависимостей

30 пакетов, 57 МБ — всё, что нужно образу сервиса. Лежат в составе решения, чтобы
**сборка образа не требовала интернета**.

## Зачем

ТЗ (разд. 8) требует офлайн только для запуска инференса, и по букве мы соответствовали
и раньше. Но если жюри соберёт образ в изолированной среде и сборка упадёт на PyPI, это
прочтётся как невоспроизводимость из кода — а это разд. 9, недопуск к оценке, а не
потеря баллов. Риск несимметричный, страховка стоит 57 МБ.

## Проверено прогоном, а не заявлением

```
podman build --no-cache --network none -t vehicle-reid-offline .
```

Сборка с **полностью отключённой сетью** проходит. Затем пакетный прогон в том же
режиме на выданном тесте даёт файлы, **побайтово совпадающие** с
[`../artifacts-final/`](../artifacts-final/) — все три.

## Как пересобрать

```bash
cd 04-solution/service
podman run --rm -v "$PWD:/src:z" -w /src python:3.13-slim \
  pip download --no-cache-dir -r requirements.txt -c requirements-lock.txt -d /src/wheels
```

Колёса собираются **в том же базовом образе**, что и сборка сервиса — иначе можно
получить пакеты под другую платформу или версию Python.

## Запасной путь

Если каталога нет, образ собирается по-старому, из сети:

```bash
docker build --build-arg PIP_SOURCE=network -t vehicle-reid-service .
```
