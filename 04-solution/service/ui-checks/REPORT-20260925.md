# Сервис ЛЦТ — рабочее пространство сравнения

База: `8e7a20580613f5a784c6ee47270a209cf1923e0e`; ветка `ui/20260925`, worktree `/home/artem/projects/lct-ui-20260925`. Владение: `service/app/static/**`, `service/ui-checks/**`; API/demo и inference принадлежат ведущему. Данные организатора остаются вне Git.

## Принятый brief

Профессиональное место сопоставления настоящих кадров: выразительная типографическая обложка → крупный query и bbox → API-поиск → обычное парное сравнение → дополнительный разбор первой OSNet → выгрузка точного результата. Vanilla и полностью локальные ресурсы; две темы. Навигация: поиск, качество/метод, материалы. Никаких обещаний вероятности совпадения или полной независимости от пластины.

Визуальный приём: угловые метки bbox связывают выбранный объект и парное сравнение. Montserrat SemiBold — display, Adwaita Sans — текст, системный mono — числа. Светлая основа #F4F6F7, текст #17252E, акцент #286984; тёмная основа #111A20, текст #EDF2F5, акцент #9DCDDF. Карты вкладов сохраняют красный #E34948 и синий #2A78D6.

## Контракт и приёмка до изменений

SearchResponse и ранжирование не меняются. Каждая выдача и экспорт принадлежат immutable snapshot кадра, bbox, top-k и threshold. Изменение входов снимает старые результаты; все асинхронные ветви проверяют revision и отменяются при устаревании. Ошибка explain не уничтожает поиск. Demo использует allowlist оригинальных query через `/api/demo`, затем настоящий `/api/search`.

Нужны RED на baseline и GREEN после исправления: delayed real API across bbox/file, stale export, load-below/explain race. Positive control — неизменный query успешно ищется/экспортируется. Browser-приёмка: 390/768/1440, обе темы, 200%, mouse/touch/numeric bbox, success/refusal/loading/errors, экспорт, отсутствие внешней сети. Исходные и финальные снимки/логи: `/home/artem/tmp/lct-ui-20260925/`.
