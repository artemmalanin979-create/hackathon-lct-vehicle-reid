## Почему он, а не b

d1 сильнее b на +0,0255 [+0,0128; +0,0379], p<0,0001, и сильнее c на +0,0310
[+0,0188; +0,0438]. Два прироста складываются почти без перекрытия: +0,043 и +0,037
по отдельности, +0,068 вместе. Вариант d2 (по матрице на каждую модель) хуже d1, вариант
d3 (1024 измерения) хуже обоих и дороже по памяти — оставлены как проверенные альтернативы.
