## 2. Шаг 1 — diffusion вместо k-reciprocal: **отрицательный результат, закрыто**

Реализация (`s1_diffusion.py`): взаимный kNN-граф **только галереи** (750 узлов), веса cos³ (γ=3 — по
Iscen et al. 2017, зафиксировано до счёта), S = D^-1/2 A D^-1/2; запрос прикрепляется вектором y (cos³ к
kq=3 ближайшим), f₀=y, f ← αSf + (1−α)y, ровно 25 итераций (restart на исходный вектор); ранжир по f,
ничьи/нули — по косинусу. Другие запросы в граф не входят. KR не наслаивается. Шесть вариантов
k∈{5,10,20} × α∈{0,8; 0,95}; **правило выбора зафиксировано до счёта**: максимум AP@10 на tune-протоколе
`04-solution/postproc/tune/` (1110/732 из train_fit-идентичностей — тот же протокол, на котором выбирались
k1,k2,λ для KR). Train_fit-векторы извлечены на узле из `crops_208.npy` (7248, ~270 мс/кроп,
`out/train_fit_osnet.npy`); KR на tune по ним: mAP 0,630 / AP@10 0,618 (опубликовано по прямым кропам:
0,636 / 0,622 — сдвиг от 256/JPEG-пути).

**Вердикт: закрыто.** Абляция номера не требуется (прироста нет).

## 3. Шаг 2 — discriminative whitening (Lw): **прирост +0,043, подтверждён**

Реализация (`s2_whitening.py`, по Radenović et al. TPAMI 2018 §3.5 / cirtorch `whiten.py`): m — среднее всех
train_fit-векторов; C — средняя ковариация разностей по **13 485 парам same-ID и разные камеры** из 1171
идентичностей **только train_fit** (∩ val = ∅ по сплиту); C_ρ = (1−ρ)·C + ρ·tr(C)/512·I; P = chol(C_ρ)⁻¹;
x → P(x−m), затем L2; полные 512 измерений; **KR(6,3,0,3) как есть** поверх. C почти вырождена (λ_min ≈ 1e-12,
λ_max 0,030, cond 3·10¹⁰) — регуляризация обязательна; cond(C_ρ) = 143 при ρ=0,1 и 17 при ρ=0,5.
**Выбор ρ зафиксирован до val**: whitening на train_fit **без** идентичностей tune-протокола (4989 строк) →
AP@10 на tune с KR; выбран **ρ = 0,5** (tune: 0,6521 против 0,6426 у ρ=0,1 и 0,6182 у KR). Для val whitening
переучен на всём train_fit.

согласовано (tune: +0,022 / +0,031 для ρ = 0,1 / 0,5; val: +0,027 / +0,043).

**Откуда прирост (позиция первого верного, KR → Lw0,5+KR):** 1: 552 → **583**; 2–5: 103 → 120; 6–10: 46 → 43;
11–20: 52 → 35; 21–50: 38 → 30; 51+: 41 → **21**. Recall@10/20/50: 0,843/0,905/0,951 → **0,897/0,939/0,975**.
Растёт и вершина, и глубина — это новая метрика вектора, а не перестановка соседей; отсюда и то, что она
обходит потолок «подъёма из глубины» из разд. 1.3 (+0,017): половина выигрыша — переупорядочивание десятки.

**Разложение (диагностика, один прогон каждое):** только центрирование (ρ=1 ⇔ P ∝ I) даёт +0,006
[+0,000; +0,011], p = 0,04; whitening ρ=0,5 **без** центрирования — +0,040 [+0,028; +0,052]. Прирост
несёт форма ковариации (подавление внутриклассовых кросс-камерных направлений), а не сдвиг среднего.

**Приёмка:**
- Разрыв «без исключения камеры / с исключением»: Lw0,5+KR **0,8609 − 0,7366 = +0,124** (KR +0,142, косинус
  +0,156 — эталон). Разрыв **сузился**; без исключения тоже растёт (0,835 → 0,861) — не запоминание точки
  съёмки. Rank-1 без исключения 0,980 (было 0,976).
- **Абляция зоны номера — не выполнена, блокер** (разд. 5): на узле нет ни val-кадров, ни
  `plate-ablation/work/emb/*.npy`, ни `boxes.json`. Слабый прокси на имеющихся старых векторах
  (`baseline/out/val_*_mask30/_gray/_mask30gray`; это **не** честная абляция — у 38,8 % кропов пластина
  выше линии 30 %): Δ(Lw0,5+KR − KR) при закрытой нижней трети **+0,033 [+0,020; +0,045]**, при обесцвечивании
  +0,027 [+0,013; +0,040], при обоих +0,028 [+0,015; +0,040] — прирост сохраняется без нижней трети и без цвета.
  Индикатор в пользу «не номер», но замена честной абляции им быть не может: Lw линеен и внутриклассово-
  устойчивые признаки (какими были бы признаки знака) он **сохраняет**, а не подавляет — проверять надо.
- Цена: матрица 512×512 FP32 + среднее = **1,05 МБ**, одно умножение 262 144 MAC на вектор (на этом узле
  ~0,11 мс/вектор в numpy), веса сети не меняются, время извлечения не растёт; обучение ~20 с CPU.

**Ограничения:** ρ выбран из двух значений; ρ=0,5 лучше ρ=0,1 и на tune, и на val, а ρ=1 (центрирование)
хуже — оптимум между 0,5 и 1 возможен, но не искался (стоп-правило «не перебирать»); k1,k2,λ у KR остались
подобранными под невыбеленное пространство — не перенастраивались (по брифу «как есть»). Train-векторы

## 5. Вердикт и вопросы

**В решение (кандидат):** `Lw ρ=0,5` (матрица `out/lw_P_rho0.5.npy` + среднее `out/lw_m_rho0.5.npy`,
учёны на train_fit) перед KR(6,3,0,3): mAP **0,6937 → 0,7366** (+0,043 [+0,030; +0,056], p<0,0005),
Rank-1 0,663 → 0,701, AP@10 0,684 → 0,730; шкала 1110: 0,520 → 0,552. Цена 1 МБ и одно умножение.
**Условие внедрения — честная абляция номера по `04-solution/plate-ablation/` на векторах Lw+KR.** До неё —
не выпускать; после неё, если контраст «пластина vs контроль» останется в нуле — выпускать, с пересчётом
порога отказа (шкала уверенности 1−d меняется вместе с метрикой; здесь порог не калибровался).

**Закрыто:** diffusion вместо KR — все шесть вариантов значимо хуже KR (−0,027…−0,067), даже общий граф
−0,012 (p=0,03). Класс «расширение соседства» на этих векторах резерва не имеет: чистый подъём ответов с
11–50 в десятку стоит ≤ +0,017, а внутри десятки диффузия только добавляет двойников.

**Не проверено:** один детерминированный кроп (нет кадров).
