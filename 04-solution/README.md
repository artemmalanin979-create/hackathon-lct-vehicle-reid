## Числа

Проверочный сплит: 1110 запросов против 750 объектов галереи, совпадения с камеры
запроса исключены — как это делает организатор. Сдаваемая конфигурация **d1_j48**:
OSNet-AIN (OMZ, MIT) + combined_v1 (наш LP-FT: RoundaboutHD MIT + CARLA Apache-2.0 +
train организатора), L2 каждого → среднее → L2 среднего → whitening (ρ=0,5) → L2,
k-reciprocal (6,3,0,3).
Источник и отбор — [`training/combined/`](training/combined/).

| | mAP | Rank-1 | Rank-5 |
|---|---:|---:|---:|
| **Полная галерея (переранжирование)** | **0.774** | **0.731** | 0.881 |
| Косинус (HTTP API и `batch --no-rerank`) | 0.732 | 0.685 | 0.882 |
| Усечение до 10 кандидатов (как в `submission.csv`) | 0.768 | — | — |

Режим отказа: переранжирование при пороге 0,5283 — **F1 0,809, TNR 0,784**; косинус
при пороге 0,5142 — F1 0,768, TNR 0,730. Разрыв по камере +0,110 (лучше прежнего
чемпиона +0,114). Абляция зоны номера для combined_v1 пройдена. Пометка честности:
отрыв от прежнего чемпиона контура +0,012 < приёмочной σ = 0,0134 — по правилу
прирост не засчитывается; переключение — явное решение Артёма при значимом
бутстрэпе (p = 0,003). Прежняя конфигурация OSNet+KR (0,694, отказ 0,806/0,777) —
в истории [`../SOLUTION.md`](../SOLUTION.md) и [`refusal/`](refusal/).

## Что сдаётся и как это проверяется

По `README.md` датасета: `submission.csv` (десять кандидатов на запрос при
галерее из десяти и более объектов),
`embeddings.npy` (все объекты теста: сначала запросы, затем галерея),
`candidates.csv` (режим отказа), плюс код, Docker и документация.
Пустые CSV, малая галерея и повторяющиеся ID имеют ограничения;
полный список — [SOLUTION.md §5](../SOLUTION.md#known-behavior-limits).

Порядок строк в `embeddings.npy` проверяется скриптом, а не глазами: вектор для
контрольных позиций пересчитывается заново свежей сессией модели и сравнивается со
строкой файла.

## Правила, по которым здесь работают

1. **Обе ветки, когда трактовка неизвестна.** Где ответ постановщика меняет число —
   считаются оба варианта, рядом, с числами. Ответ применится выбором готовой строки.
2. **Проверка обязана падать.** Проверяльщик сплита доказан намеренной порчей;
   измерительный контур — двадцатью пятью поломками, из которых десять нашла
   независимая сторона.
3. **Числа получают прогоном на чистом дереве**, а не переносят из вывода в текст.
4. **Незнание — допущение с красной отметкой**, никогда не решение.
