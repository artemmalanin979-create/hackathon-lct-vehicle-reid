# Независимость от номерного знака — измерено честно

ТЗ (разд. 9) снимает с оценки решения, использующие признаки государственного знака.
Это не потеря баллов, а дисквалификация. Значит нужен довод, который выдержит вопрос
эксперта.

Полный разбор — [`REPORT.md`](REPORT.md).

## Ответ

**Вклад зоны номерной пластины не отличим от нуля.**

Точечная оценка по основному контролю — **−0,003 mAP** (95 % доверительный интервал
[−0,011; +0,004], p = 0,40): закрыть пластину оказалось чуть **дешевле**, чем закрыть
такой же прямоугольник рядом на кузове. По пяти разным контролям оценка лежит между
−0,011 и +0,001; по самому консервативному варианту (бокс расширен на 12 %, чтобы
гарантированно накрыть пластину целиком) — +0,006 при интервале [−0,003; +0,016].

Формулировка для защиты: **верхняя граница 95 % интервала — +0,004 mAP по основному
контролю и +0,016 по самому консервативному варианту.** При mAP решения 0,657 это до
1,6 пункта метрики, то есть около 2,4 % от достигнутого значения.

*(Формулировка исправлена: в первой версии здесь стояло «меньше процента метрики» — это
арифметически неверно, 0,016 при 0,657 составляет 2,4 %, а не долю процента.)*

**Цвет пластины не даёт ничего отдельно от цвета кузова.** Обесцвечивание только зоны
пластины стоит 0,0027 mAP — в 32 раза меньше, чем обесцвечивание всего кропа. Вектор
при этом почти не двигается: косинус с исходным 0,9983.

## Почему прежнему числу нельзя было верить

Первая абляция закрывала нижние 30 % кропа, давала −0,108 mAP, и мы делали вывод, что
решение не держится на пластине. Теперь измерено: **38,8 % найденных пластин лежат
целиком выше** линии нижних 30 %, у 48,4 % выше неё центр. То есть больше трети пластин
та абляция просто не трогала — а −0,108 было ценой потери 30 % пикселей.

## Как найдена пластина

Без обучения и без чужих весов. Ключ — не гладкость и не резкость (того и другого полно
на стекле и капоте), а **размер области постоянного цвета**: пикселизация оставляет
ячейки своего масштаба, у текстуры они мельче, у гладкой панели крупнее. Детектор ищет
окно с высокой плотностью «ячеистых» пикселей и наращивает границы, пока размер ячейки
согласован.

Порядок работ выбран так, чтобы его нельзя было подогнать: детектор настраивался
**только на обучающей выборке**, разметка для проверки делалась **вслепую** — 36
случайных кропов валидации размечались руками до того, как был посчитан выход детектора
на них.

| Качество локализации (36 размеченных кропов) | |
|---|---:|
| центр бокса внутри размеченной пластины | **34 из 35** |
| покрытие площади пластины, медиана | 0,857 |
| IoU, медиана | 0,558 |
| доля площади кропа под маской, медиана | **2,7 %** (против 30 % у первой абляции) |

## Схема измерения

Пластина закрывается — и сравнивается **не** с «ничего не закрыто», а с закрытием
**того же самого прямоугольника**, перенесённого туда, где пластины нет: сдвиг по
вертикали, зеркально, вбок, и дважды в случайное место. Та же площадь, та же форма, тот
же сдвиг статистик на входе сети. Разница между ними — и есть вклад пластины.

| Что закрыто | mAP | Δ |
|---|---:|---:|
| ничего | 0,6566 | — |
| **зона пластины** | 0,6513 | −0,005 |
| контроль: сдвиг по вертикали | 0,6480 | −0,009 |
| контроль: зеркально | 0,6505 | −0,006 |
| контроль: вбок | 0,6409 | −0,016 |
| контроль: случайно (два seed) | 0,6524 / 0,6513 | −0,004 / −0,005 |

Ни один контраст не значим в «нужную» сторону. Единственный значимый (p = 0,029)
направлен **против** гипотезы: полоса на фарах и крыле дороже пластины.

Независимое подтверждение, не связанное с метрикой ранжирования: закрытие пластины
двигает вектор слабее (косинус 0,9905), чем закрытие того же бокса, сдвинутого по
вертикали (0,9851) или вбок (0,9751).

## Чего это НЕ доказывает

Измерена ценность **зоны** пластины для конкретных весов без обучения. Это не
доказательство, что сеть в принципе не умеет пользоваться признаками знака, и результат
**придётся пересчитать после любого дообучения** — особенно если дообучение пойдёт на
этих же размытых кадрах.

Маска накрывает пластину не целиком (медиана покрытия 0,857), разметка одна и сделана
одним человеком: про hit-rate честно говорить «уверенно больше 80 %», а не «97 %».
Оба эффекта работают на занижение измеренного вклада — поэтому нулевой результат
проверен отдельно вариантом с расширенным боксом.
