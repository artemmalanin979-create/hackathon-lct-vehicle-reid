Итог: **8/10 ловится тестами; M5 и M8 — пропуски**.

- **M8 (потоковый CSV)** — единственный пропуск с пользовательски видимой
  поломкой штатного CLI: `app.batch --query <FIFO>` при снятом guard зависает
  (preflight читает FIFO до EOF, затем `read_rows` ждёт повторного писателя).
  Это ровно класс регресса job_90-91. Теста, держащего guard, в наборе нет.
  На обычных файлах guard неактивен — на них поведение неизменно.
- **M5 (research-контракт)** — меняется семантика только для вызывающих с
  `suffixes` без `""` (research/loader extractors с `(".jpg",)`); штатный batch
  всегда передаёт `""` в suffixes и не затрагивается. Эффект: ID с расширением
  изображения трактуется литерально вместо перебора.

## Ложные срабатывания и пропуски (имена, параметры, потоки)

18 изолированных кейсов (`probes_names.py`, прогонялись и на чистом коде, и под
каждой мутацией) и 8 CLI-прогонов с реальной моделью (`probes_streaming.py`,
5 строк из валидационного сплита). **Ложных отказов валидных имён не найдено.**

| Условие | Результат |
|---|---|
| ID без расширения (`stem` → `stem.jpg`) | принимается, верный файл |
| Точное имя без image-расширения (`valid.dat`) | принимается как точное имя (последний шаг перебора) |
| Несколько точек (`cam.2026.09.24`, `rec.2026-09-24T12.00`) | дописывание `.jpg` и т.д., верно |
| Верхний регистр: `UPPER.PNG` (полное) / `Name.V1` (точечное) | литерально / `Name.V1.jpg`, верно |
| Пробел (`my car.v1`, `my car.jpg`) | верно в обоих режимах |
| Unicode (`авто.v2`, `авто.png`) | верно в обоих режимах |
| Symlink (`alias.v2.jpg → target.jpg`) | принимается, пиксели цели |
| Файл без прав на чтения (chmod 000, не-root) | preflight пропускает (проверка `is_file`), чистый отказ на этапе декодирования → batch exit 2. Ложного принятия нет; в контейнере jury тест бессмыслен (root читает всё) |
| batch=1 vs batch=32 | embeddings расходятся ≤ 6.7e-08 (документированный float32-дрейф), нормы в допуске, выходные файлы на фикстуре побайтово совпали |
| batch=1000 > числа строк | rc=0, embeddings и CSV побайтово как у batch=32 |
| `--no-rerank` | шкала cosine, косинусный порог по умолчанию, embeddings как у rerank-режима |
| `--batch 0` / `--batch -1` | rc=2, чистая ошибка argparse, вычислений нет |
| Потоковый CSV (FIFO как query и как gallery) | rc=0, embeddings и оба CSV побайтово равны обычному CSV |

## Граница защиты (обе стороны)

| Условие | Результат |
|---|---|
| `named.png`, тень `named.png.jpg`, точного файла нет | FileNotFoundError / preflight exit 2 — тень не подставляется |
| `named.png` повреждён, тень валидна | CropInputError на повреждённом файле — fallback на тень нет |
| `named.png.jpg` как image_id при наличии только `named.png` | FileNotFoundError — имени не «обрезается» расширение, в несуществующее не разрешается |
| `frame.v1.png` при наличии только `frame.v1.png.jpg` | FileNotFoundError — точечный ID не отменяет защиту своего полного имени |
| `exact.png.jpg` (сам себя, файл есть) | разрешается в себя |
