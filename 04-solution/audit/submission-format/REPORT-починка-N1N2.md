## Проверенные числовые параметры

| CLI / параметр | Допустимые значения и проверенное поведение |
|---|---|
| `app.batch --batch`, `app.load_gallery --batch`, baseline/fastreid `--batch` | Целое > 0; 0 и −1 отвергаются до работы. Штатный batch=32 проверен тестами и реальным инференсом. |
| `app.batch`, baseline, fastreid: `--threads` | Целое ≥ 0; 0 сохраняет выбор runtime, отрицательные отвергаются. Также защищён прямой конструктор Embedder. |
| `app.load_gallery --wait` | Конечное число ≥ 0; 0 — одна проверка готовности без ожидания. −1, NaN, ±Inf отвергаются. |
| `app.batch --threshold`, `REID_THRESHOLD`, `REID_THRESHOLD_RERANK` | Любое конечное число. **−1, 0, 1.1 сохранены**: вне обычной шкалы это осмысленное принять/отклонить всё. NaN/±Inf не допускаются, включая выбранное значение из env. |
| `REID_RERANK_K1`, `REID_RERANK_K2`, `REID_RERANK_LAMBDA` | В режиме KR: K1/K2 ≥ 1, конечная λ ∈ [0,1]. Проверены нули, отрицательные, NaN/±Inf и выход λ за диапазон. В `--no-rerank` неиспользуемые параметры KR не мешают запуску. |
| baseline `--mask-bottom` | Конечная доля [0,1]. Отрицательное/NaN раньше молча выключали маску, значения >1 молча меняли смысл абляции; теперь ранний отказ. |
| baseline/fastreid `--limit` | **Сохранён signed Python-срез**: 0 — все строки, N>0 — первые N, N<0 — убрать хвост. Ранее работавший `--limit -1` подтверждён неизменённым runtime-тестом. Пустой результат среза — ошибка до модели. |
| `eval/reid_metrics.py --top-k`, `--rank-ks`, `--threshold` | Уже имели проверки положительных рангов и конечности порога; менять не потребовалось. Все **60** тестов контура проходят. |
| `reproduce/run.py` | Собственных числовых флагов нет, batch=32/threads=2 заданы документированным сценарием. Полный прогон ниже. |
