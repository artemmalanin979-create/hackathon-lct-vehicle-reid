# Сколько в наших 0,774 держится на данных, а сколько на выборе

Мы перебрали на одной и той же валидации десятки вариантов: бэкбоны, whitening, ансамбли,
гейты, переранжирование, больший вход, третью и четвёртую ветвь. Каждый раз брали лучший.
Это ровно та процедура, которая завышает результат, — и величина завышения до сих пор не
была измерена. Настоящий тест у организатора мы увидим один раз, поэтому цену собственного
перебора лучше знать заранее.

Здесь измеряется не модель, а наша работа с ней. Обучение не запускалось, конфигурация не
менялась — только счёт по сохранённым векторам.

## Что устойчиво

**Выигрыш над базовой моделью.** OMZ OSNet-AIN без дообучения даёт 0,693658, наша сборка —
0,774092, разница **+0,080433**. Она положительна:

- во **всех 400 половинах** валидации (200 случайных разбиений по машинам, обе половины);
- во **всех 87 проверках** с удалением одной камеры из галереи, диапазон [0,0757; 0,0849].

Ни одно разбиение и ни одна камера не переворачивают вывод. Сильнее всего выигрыш проседает
при удалении камеры 95 — до 0,0757, и то в основном из-за смены состава запросов, а не из-за
самой камеры.

## Что не переносится буквально

**Сама цифра 0,774 — свойство этой валидации, а не константа.** По 400 половинам:

| | mAP d1_j48 |
|---|---:|
| медиана | 0,774092 |
| стандартное отклонение | **0,019214** |
| центральные 95 % | [0,737940; 0,810237] |
| полный размах | [0,713621; 0,830897] |

То есть на выборке вдвое меньшего размера из тех же машин результат гуляет примерно ±0,019
по одному отклонению. Обещать 0,774 на незнакомых данных нельзя.

## Оптимизм отбора — главное число

Процедура: на каждом из 200 разбиений выбираем лучший вариант по половине A (ровно так, как
мы выбирали по всей валидации) и смотрим, что он даёт на половине B.

| | значение |
|---|---:|
| оптимизм A→B по формуле задания | **0,012732** |
| он же после симметризации A→B и B→A | **0,006902** |
| победитель A **не** лучший на B | **188 из 200 (94 %)** |
| средний ранг выбранного варианта на B | 3,8 из 7 |

Симметризация нужна потому, что случайные половины A в этих seed оказались в среднем легче:
у фиксированной сборки AB, которую вообще не выбирали, разрыв A−B уже +0,0062. Честная
оценка эффекта именно выбора — **0,0069–0,0079** mAP (расширенный архив из 45 уникальных
замеров даёт 0,0079).

Проще говоря: **выбрать лучший вариант по этой валидации означает завысить результат примерно
на 0,007 mAP** — даже когда перебираешь всего семь честно посчитанных сборок.

## Почему мы не меняем конфигурацию на ABD

Побочный результат, который надо назвать прямо: по частоте побед на половинах наша сборка
**не лидер**.

| Сборка | mAP на всей валидации | побед из 400 половин |
|---|---:|---:|
| ABD (+ OSNet@256) | 0,777874 | **192 (48,0 %)** |
| ABCD | 0,776369 | 79 (19,75 %) |
| **AB = d1_j48 — сдаём** | 0,774092 | 67 (16,75 %) |
| ABC | 0,774196 | 52 (13,0 %) |
| остальные | — | 10 (2,5 %) |

ABD выигрывает втрое чаще. Тем не менее конфигурацию не меняем, и вот почему:

**Прирост ABD равен 0,003782 — это меньше измеренного здесь оптимизма отбора 0,0069.**
То есть предпочесть ABD по этой валидации — ровно тот самообман, который мы только что
измерили: величина, за которой мы бы погнались, меньше систематического завышения самой
процедуры выбора. Добавьте к этому p после поправки Холма = 1,000 (job_69) и цену кадра
662 мс против 372 мс — почти вдвое.

Половины сильно перекрываются и происходят из одной валидации, поэтому частота побед не
является независимым доказательством. Средняя ранговая корреляция порядка семи сборок между
половинами — всего **0,235**: порядок близких вариантов между собой неустойчив, и это ещё
одна причина не гнаться за третьим знаком.

## Что мы вправе утверждать перед жюри

Выигрыш над готовой моделью из коробки — настоящий: он выдержал все половины и все
исключения камер. Конкретное число 0,774 — свойство нашей валидации; на закрытом тесте оно
будет другим, и, вероятно, ниже: только измеренный вклад выбора среди сохранённых вариантов
составляет 0,007–0,013, а адаптация за всю историю работы не измерена вовсе.

Честно сказать «доли истинного качества и подгонки в 0,774 раздельно не определены» —
правильнее, чем называть одну цифру без оговорок.

## Границы самой проверки

Половины и бутстрэп не превращают эти данные в независимый тест. Галерея и контекст
переранжирования фиксированы, делятся только метки оцениваемых запросов; модели и whitening
созданы до разбиения. Проверка с удалением камеры — это выпадение известной камеры из
галереи, а не обучение без неё и не новые камеры. Даже расширенный архив хранит замеры уже
адаптивно созданных моделей.
