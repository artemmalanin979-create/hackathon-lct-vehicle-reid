**Оценка допуска по ТЗ §12:** в текущем виде я бы **не принял комплект как полностью воспроизводимую сдачу**. Архитектура и алгоритмы описаны, обоснование отказа есть, веса и автономная сборка сервиса подтверждены. Однако главная цель §12 — возможность полного воспроизведения продемонстрированных результатов сторонним исполнителем — не выполнена на реально доступном комплекте. Существенные основания: заблокирован полный запуск без внешней подготовки, не пересчитаны головные числа, отсутствует часть фактически использованного обучения и полного списка его версий. По тексту §7 невоспроизводимые внешние данные создают отдельный риск недопуска; по имеющимся материалам нельзя объявить всю цепочку данных ни подтверждённой, ни заведомо запрещённой. Отсутствие организаторских изображений в Git само по себе не доказывает дисквалификацию: жюри может иметь их. Но для стороннего воспроизведения необходимо явно обеспечить и проверить этот путь, а не засчитывать доступ автора к локальному `data/`.

Основание оценки — [текст ТЗ, §12](evidence/documentation-clone/00-task/tz.txt), строки 313–331; связанные требования к внешним ресурсам/сдаче — строки 187–217. Это оценка готовности предоставленного комплекта; решение организаторов не получено.
