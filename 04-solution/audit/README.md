# Аудит воспроизводимости

ТЗ (разд. 9) снимает с оценки решения, которые не воспроизводятся из предоставленного
кода. Поэтому документацию писал не тот, кто писал решение, и главной его задачей было
не описать, а **пройти путь стороннего человека и записать, где он спотыкается**.

Полный отчёт — [`reproducibility-audit-01.md`](reproducibility-audit-01.md).
Сама документация — [`../../SOLUTION.md`](../../SOLUTION.md).

## Что работает

Основной инференс и метрики воспроизводятся. Проверено не на словах:

| Проверка | Результат |
|---|---|
| Полный прогон в контейнере с отключённой сетью, валидация и тест | по 1860 объектов, успех |
| Нативный прогон против контейнерного | все три файла **побайтово** одинаковы |
| Актуальный прогон с переранжированием на тесте | 1078 запросов с кандидатами, 32 отказа |
| Тесты измерительного контура командой из документации | 60 тестов, без ошибок |
| Данные организатора | перечитаны и захешированы все 11 416 изображений |
| Сверка внешних исходников с манифестом | размеры и sha256 всех шести записей совпали |

## Что не работает — 18 конкретных мест

Каждое подтверждено реальным падением с логом, а не предположением. Самые важные:

**Сборка образа требует сети.** В README сервиса стояло «сама сборка и запуск сеть не
используют» — это неверно наполовину: `Dockerfile` ставит зависимости через `pip`, и
сборка с `--no-cache --network none` падает на разрешении имени PyPI. Офлайн работает
**запуск**, а не сборка. Формулировка исправлена.

**Веса в чистом клоне отсутствуют** — `*.onnx` в `.gitignore`, сборка падает на проверке
хеша. Ровно та проблема, которую нужно решить при переносе в репозиторий сдачи.

**Скрипты исследовательских этапов не запускаются из репозитория.** У `baseline`,
`postproc`, `refusal`, `plate-ablation` часть скриптов ожидает файлы, которых в
репозитории нет (промежуточные векторы, ручная разметка), или абсолютные пути к
каталогам, где они писались. Основные числа воспроизводятся командами из `SOLUTION.md`,
исторические отчёты целиком — нет, и это сказано прямо.

**Арифметическая ошибка в нашем тексте.** Про абляцию по пластине было написано, что
верхняя граница +0,016 mAP «меньше процента метрики». Это неверно: при значении 0,657
она составляет 2,4 %. Исправлено.

**Загрузка галереи не входит в `up`.** Сервис-загрузчик убран в профиль `tools`, поэтому
после `docker compose up` галерея пуста и поиск отвечает 409. В документации это названо
явно, отдельной командой.

## Чего в аудите нет

Docker не запускался — на машине только podman 5.8.2. API проверялся через тестовый
клиент FastAPI с настоящим Qdrant, но не через опубликованный порт в браузере.
Полного lock-файла зависимостей с хешами в репозитории по-прежнему нет.
