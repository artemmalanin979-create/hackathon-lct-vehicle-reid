## Протокол до просмотра результатов новых комбинаций

- База A+B: A = OMZ OSNet@208, B = combined_v1@208. Дополнения C = combined_256@256, D = OMZ OSNet@256, E = combined_v1@256. Проверяются ABC, ABD, ABE, ABCD, ABCE, ABDE (N=6).
- Каждый вектор приводится к float64 и L2; сумма равновесных ветвей L2-нормируется перед whitening, как в исходном d1_j48. После whitening — L2. Whitening для каждого сочетания заново на 7248 own train_fit, rho=0.5; KR=(6,3,0.3).
- Основная статистическая семья: шесть сравнений KR mAP против базы. B=4000, seed=20260921, парные ресэмплы известных запросов; sigma=0.0134. Дополнительно — bootstrap с кластерами vehicle_id.
- Для p применяется Holm step-down. Помимо обычного CI95 сохраняются консервативные одновременные интервалы с семейным покрытием 95%: Bonferroni, квантили 0.05/(2*6) и 1-0.05/(2*6). Это явно обозначается, а не выдаётся за обычный CI95 или интервал Холма.
- Прирост подтверждается только при положительной дельте, p_Holm<0.05 и скорректированном интервале целиком выше нуля. Дельта в единицах заданной sigma приводится отдельно. Веса и гиперпараметры не подбираются.
- worker-vm доступен; нагрузка перед началом 0.02/0.06/0.11. Вычисления ограничиваются двумя потоками.
- Уточнение происхождения: README whitening/final относится к старому ain_v2; текущий combined_v1 — job_48, а не ain_v2. Переиспользуется штатный reid_metrics.py (SHA-256 79fba705…aaeabe37ffec), его код не меняется.
