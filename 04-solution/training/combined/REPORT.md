## 6. Вердикт

Критерий приёмки зафиксирован заранее: σ(mAP) = 0,0134; отрыв меньше σ — не прирост.
Числа — из `out/s02_metrics.json` и `out/plate/plate_ablation.json`.

1. **Одиночная combined_v1 (j48): KR mAP 0.7423 / R1 0.6959.** Ниже чемпиона d1_w1.0
   (0.7621 / 0.7175): Δ = −0.0197, CI95 [−0.0336, −0.0061], p = 0.002 — значимый дефицит.
   Выше эталона OSNet (0.6937): Δ = +0.0487, CI95 [+0.0294, +0.0679], p ≈ 0.
   → Ответ по протоколу: **объединённые данные не обошли ансамбль** (одиночная модель).
2. **Ансамбль d1_j48 (Lw→l2(OSNet+j48)): 0.7741 / 0.7308** — выше чемпиона по обеим
   метрикам; бутстрэп значим (Δ = +0.0120, CI95 [+0.0040, +0.0205], p = 0.003), однако
   отрыв +0.0120 < σ = 0.0134 → по приёмочному правилу **прирост не засчитывается**.
   Тройной ансамбль d1_3 = 0.7640 (Δ = +0.0019, p = 0.594) — паритет с чемпионом.
   Остальные конфигурации (c_j48, d3_j48, c3) — ниже или в паритете с чемпионом.
3. Разрыв по камере у j48 +0.1270 — лучше OSNet (+0.1417), хуже чемпиона (+0.1144);
   у лучшего ансамбля d1_j48 +0.1103 — лучше чемпиона (кросс-камерная обобщаемость
   немного улучшилась, но не пороговая разница).
4. Зависимости от зоны номера нет (§5).

**Итог: против 0.7621 / 0.7175 прироста по критерию приёмки нет.** Combined-модель
одиночно существенно лучше исходного OSNet, но до уровня чемпиона-ансамбля не дотянула;
ансамбль с её участием формально выше чемпиона, с статистически значимым отрывом,
но отрыв ниже приёмочного σ = 0.0134. Сглаживания нет: заявлять превышение нельзя.
Практический вывод: дообучение на объединённом наборе полезно как замена ain_v2
внутри ансамбля (d1_j48 — лучшая конфигурация прогона), но как самостоятельная
замена ансамбля не работает.
