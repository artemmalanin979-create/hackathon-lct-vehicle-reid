## Что нужно, чтобы поднять

1. **Квоты** — обе, не одна: `compute.instanceT4Gpus.count` на облако **и**
   `compute.instanceT4Gpus.count.ru-central1-d` на зону. Документация подтверждает T4
   только в зоне `ru-central1-d`.
2. Профиль `yc` `lct2026` с ключом сервисного аккаунта (`~/.config/lct2026/`, вне git).

## Команды

```
./up.sh              # машина lct-gpu, зона d, образ ubuntu-2204-lts-cuda-12-2, печатает IP
PREEMPTIBLE=1 ./up.sh   # то же, прерываемая — в четыре раза дешевле
./status.sh          # что существует в каталоге и сколько стоит в час — запускать после каждого прогона
./down.sh            # снести всё: машина с диском, адреса, подсеть, сеть; идемпотентно
```

Все параметры — в `lct.env`, тарифы — в `prices.json` (единственный источник цифр для
`status.sh`). Синтаксис проверен `bash -n` и `shellcheck` 0.11 без замечаний; флаги `yc`
сверены с 1.34.0 ([checks.txt](checks.txt)); `status.sh` прогнан на заглушке с известным
ответом; `up.sh`/`down.sh` — только в `--dry-run`. **Первый настоящий `up.sh` — со
`status.sh` рядом.**

## Что ставит cloud-init

Ubuntu 22.04, драйвер 535, CUDA 12.2 из образа; поверх — Python 3.12 через `uv`, PyTorch
2.14 (cu126, совместим с драйвером 535 по minor-version compatibility), `onnxruntime-gpu`,
`timm`, `transformers`, `open_clip_torch`; Blender 4.5.14 tarball в `/opt/blender`.
Пакеты драйвера и ядра — на `apt-mark hold`, иначе апгрейд без перезагрузки ломает CUDA.
Ожидание после старта — около 12 минут (≈ 4,7 ГБ загрузок), это ≈ 16 ₽ оплаченного времени.

⚠ `yc config list` печатает приватный ключ профиля в терминал. Пользоваться
`yc config get <поле>`.
