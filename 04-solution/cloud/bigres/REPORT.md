# Подготовка большого входа — job_63

Статус: работа идёт. GPU не выделен; облачные ресурсы не создавались.

Готовятся `run_bigres.sh`, извлечение признаков ONNX, вызовы штатного eval, абляция номера, CPU-проверки и оценка бюджета. Измеренные результаты будут дописываться по мере выполнения. Коммиты не создаются.

Подтверждённое ограничение: исходный `combined_v1` принимает только 208×208; OSNet-AIN принимает все четыре размера. Проверяется безопасное изменение входных метаданных ONNX без изменения весов.

Путь без обучения подтверждён: у combined_v1 достаточно заменить фиксированные H/W входа ONNX динамическими метками. Узлы графа и веса не меняются; выход остаётся 512-мерным на 208/256/320/384. Для переносимости готовится `payload/` с проверками SHA-256.
