## Усреднение и исключение

- H07: два запроса с AP 1 (один P на rank 1) и 5/12 (два P на ranks 3,4): mAP=17/24; взвешенное по числу P ошибочно даёт 11/18. AP второго = (1/3+2/4)/2 = 5/12.
- H08: валидный запрос AP=1, подлинно отрицательный, и запрос с верными только на своей камере: mAP=1 по одному валидному. Деление на три даст 1/3. Последний запрос исключается также из отказов в нашем временном протоколе; отрицательный сохраняется для TNR.
- H09: same-camera N впереди cross-camera P. Market-маска оставляет N: AP=1/2; all-same-camera удаляет N: AP=1. Same-camera P перед cross-camera N,P удаляется, результат AP=1/2.
- H10: одинаковые scores у P и N; стабильный порядок галереи даёт AP=1 или 1/2 при перестановке столбцов; с постоянным gallery_key порядок фиксирован. Для шести элементов с одним P диапазон AP=[1/6,1], Rank-5=[0,1].
- H11: пустая галерея или отсутствие валидных запросов — mAP/CMC/mINP не определены (`None`), не 0 и не 1. Отрицательный запрос к пустой галерее даёт TNR=1; пустая выборка даёт TNR=None.

## Случайный уровень: независимый вывод

Для N допустимых кандидатов, M>0 верных, случайной равномерной перестановки, H_N=sum(1/r):

E[AP_step] = H_N/N + (M-1)(N-H_N)/(N(N-1)), N>1.

Вывод: при положительном на позиции r ожидаемое количество положительных выше равно (r-1)(M-1)/(N-1); вероятность положительного на r равна M/N. Подставляем в определение AP. N=1,M=1 отдельно даёт 1.

E[Rank-k] = 1 - C(N-M,min(k,N))/C(N,min(k,N)); E[INP] = sum_{r=M}^N (M/r) C(r-1,M-1)/C(N,M).

При M=1 AP=INP=1/r; для N=6 среднее всех перестановок H_6/6=49/120, Rank-1=1/6, Rank-5=5/6. Дополнительно проверяется перебор всех расположений P при N<=7 и Monte Carlo с N=100,M=4. Случайный AP не равен в точности доле M/N из-за конечного размера галереи.

Параметры Monte Carlo зафиксированы до прогона: seed=20260915, 5000 запросов, независимые uniform[0,1) scores, N=100,M=4. Допуск — пять стандартных ошибок среднего, рассчитанных по разбросу отдельных запросов; дополнительная грубая проверка mAP<0.15. Это статистическая проверка, а не доказательство для любого seed. Равномерный случайный ввод сам по себе не отличит сортировку по возрастанию от сортировки по убыванию.
