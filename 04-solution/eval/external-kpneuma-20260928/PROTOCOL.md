Протокол: **полный тестовый набор**, без отбора удачных кадров. Имена
`XXXXXXXX_YY_ZZZZ.png`: `XXXXXXXX` — идентичность машины, включая код видео;
`YY` — Virtual Loop Detector (VLD), `ZZZZ` — номер кадра. У всех 318 запросов
есть ровно одна размеченная пара в галерее с другим VLD. Галерея и запросы
сортируются по полному имени файла. PNG уже являются кропами ТС: bbox — весь
кадр. Препроцессинг, модели, whitening, cosine и KR `6/3/0.3` — без изменений,
через код сдаваемого сервиса. Нового порога отказа не выбираем.

Оценка: полный mAP, Rank-1/5 и mINP по существующему
`04-solution/eval/reid_metrics.py`; фильтр `market` исключает ту же
идентичность и тот же VLD. Оба режима — cosine и KR — считаются на одних
эмбеддингах. Для ориентира: положительный контроль с идеальным ранжированием
и отрицательный с фиксированными случайными признаками (seed `20260928`).
Доверительный интервал mAP — парный bootstrap по 318 ID, 2000 повторов с тем
же seed; никаких настроек модели по результату. Отчёт должен указать версии,
время, число выполненных запросов и все ограничения.

**Граница смысла:** VLD — виртуальные точки на траектории одной аэросъёмки,
не независимые физические камеры ЛЦТ. У каждой идентичности одна релевантная
пара, поэтому AP запроса равен обратному рангу. Это внешний тест retrieval
с сильным изменением ракурса и масштаба, а не оценка официального закрытого
теста. Архив не был источником обучения релиза. Отдельная лицензия архива в
репозитории не указана; изображения остаются локально и не публикуются.
