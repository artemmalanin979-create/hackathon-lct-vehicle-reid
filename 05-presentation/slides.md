### Заметки докладчика и источники

Путь: галерея уже подготовлена администратором → оператор выбирает демонстрационный

Скриншот показывает собранную версию сервиса, без localhost, подставных результатов
и персональных контактов. Экспорт относится к текущему запросу. Ошибка объяснения
не должна разрушать результаты поиска. Отказ — успешный пустой ответ, 422/409/503 —
отдельные ошибки ввода, незагруженной галереи и недоступного хранилища.

API использует точный cosine (`exact=True` в Qdrant), по умолчанию top_k=10 с фильтром
score ≥ 0.5141976914190476 до округления. Ни один score не является вероятностью.
Пользователь может посмотреть кандидатов ниже порога; это не отменяет исходного отказа.
Пакетный KR имеет другую семантику и порог. Разбор относится к первой OSNet, поиск —
к ансамблю + whitening; эту границу нельзя скрывать.

Источники: `04-solution/service/app/api/main.py`, `api/store.py`, `core/config.py`,

и `assets/ui-provenance.json`; кадр получен через реальный API в локальном браузере.

## 3. Две ветви. Один признак из 512 чисел

### Заголовок

**Две ветви. Один признак из 512 чисел**

### Заметки докладчика и источники

Показываем настоящее устройство дескриптора. Вход — предоставленный bbox, RGB,
PIL bilinear 208×208, float32 0…255 NCHW. Встроенная нормировка ONNX уже включена,
внешняя ImageNet-нормировка не применяется. Две сети получают один кроп.
L2 каждой 512-мерной ветви → среднее → L2 → y=(x−m)@P.T → L2.
Whitening 512×512, ρ=0,5, обучен по межкамерным разностям на train_fit.

combined_v1 — наше LP-FT дообучение OSNet-AIN на RoundaboutHD (MIT), CARLA-ReID
(Apache-2.0) и train организатора. Предобучение исходной OSNet: OMZ 2022.1.
Сначала обучали classifier, затем частично размораживали backbone; не сеть с нуля.
Рецепт включает MCNL и MixStyle, баланс камер, hflip/pad-crop. Это цели механизмов,
отдельной абляции причинного эффекта каждого на d1_j48 не было.

Почему backbone: историческая проверка cosine дала OSNet mAP 0.656569 против R50-IBN
0.2384, на слайде округлено 0,657 / 0,238. Эти числа нельзя сравнивать как эффект
нашего дообучения. API: точный cosine. Batch: KR, k1=6, k2=3, λ=0,3, на всех query+gallery;
результат зависит от состава batch, автоматического fallback на cosine нет.

Источники: `04-solution/service/app/core/model.py`, `preprocess.py`, `config.py`;
`training/combined/journal.md`, `training/combined/REPORT.md`, `training/src/README.md`;
`04-solution/postproc/REPORT.md` §2; `SOLUTION.md` §§2, 9, 11.
Диаграмма состоит из редактируемых объектов PPTX; отдельный SVG и DOT — `assets/`.

документацию проверяются отдельно; наличие имени SourceCraft не доказывает доступ.

## 11. Демонстрация готовится к внешнему доступу

### Заголовок

**Демонстрация готовится к внешнему доступу**

### Заметки докладчика и источники

Финальный сценарий защиты: загрузить разрешённый демонстрационный кадр → уточнить
рамку → выполнить настоящий API → сравнить с первым кандидатом → показать явный отказ
на отдельном подготовленном примере → сохранить CSV/JSON текущего ответа.
Если сеть недоступна, резервная демонстрация выполняется локально с тем же приложением,
