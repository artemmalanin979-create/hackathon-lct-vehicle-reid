## Реальная резервная демонстрация

Снимки финального UI сняты через настоящий API; слайд 7 содержит принятый snapshot
из presentation-shots.cjs. Полная проверка сценария защиты с отключённым интернетом
должна иметь отдельный журнал. Скриншот не считается этой репетицией. Для неё
сохраняем SHA сборки, команды запуска, версию API, кадр и bbox, время запроса,
ответ JSON/CSV и сетевой журнал.

1. Открыть `https://demo.lct.iamcp.ru/`, убедиться в health и готовой gallery. Резерв — подготовленный Compose по SOLUTION.md.
2. Выбрать разрешённый demonstration image, уточнить bbox, выполнить поиск.
3. Открыть сравнение и разбор, сохранить JSON/CSV; проверить идентичность текущему кадру.
4. Выполнить отдельный заранее проверенный отказ и сохранить его, не подбирая порог на сцене.
5. Отключить интернет для репетиции, повторить шаги на локальных ресурсах.

Для текущего демо первый `demo-street.jpg` — query
`e03daa7cd69147cf9ffcfe59b6f1ff74`, bbox [734,341,608,551],
top-1 `e429a2e164a24919a12edcc8d4ea8f09`, cosine 0.678976 при пороге
0.5141976914190476; отдельный demo edge показывает отказ. Ответ получен
из настоящего опубликованного API и закреплён в `assets/ui-provenance.json`.
У test нет меток и camera_id; пример не должен описываться как доказанная
межкамерная пара. Отдельная репетиция без интернета ещё не подтверждена журналом.
Список вероятных вопросов — вопросы-и-ответы.md; измерения — числа.md и заметки deck.
