## Ключевое решение: слепок — это артефакт, а не внутреннее состояние

Постановщик просит **компактный слепок, передаваемый между городскими системами**.
Значит, проектируем не только модель, но и **формат**:

```jsonc
{
  "schema": "vfp/1",             // версия схемы
  "model": "reid-r50ibn@a1b2c3", // версия модели — слепки разных версий несравнимы
  "embedding": "<base64 int8>",  // квантованный вектор фиксированной длины
  "attrs": { "body": 3, "color": 7, "make_model": 142 },
  "marks": [ ... ],              // особые приметы
  "quality": 0.82                // насколько кропу можно верить
}
```

Из этого следуют требования, о которых легко забыть:

- **Версия модели внутри слепка.** Слепки, снятые разными версиями, сравнивать нельзя.
  Без этого поля городская система однажды сравнит несравнимое и не заметит.
- **Правило сравнения — часть формата**, а не деталь нашего сервиса: потребитель должен
  уметь сравнить два слепка сам, не обращаясь к нам.
- **Оценка качества** рядом со слепком. Плохой кроп (сильное перекрытие, ночь, смаз) даёт
  ненадёжный слепок, и потребитель должен это видеть, а не получать уверенный мусор.

## API (эскиз)

| Метод | Назначение |
|---|---|
| `POST /embed` | кадр/кроп → слепок |
| `POST /search` | слепок → ранжированные кандидаты с объяснением |
| `POST /match` | два слепка → похожесть и вердикт по калиброванному порогу |
| `POST /cluster` | пакет событий → группы «один автомобиль» |
| `GET /health`, `GET /version` | версия модели и схемы слепка |

## Объяснимость

Для каждого кандидата возвращаем, **чем именно похожи**: совпавшие атрибуты, совпавшие
приметы, вклад в итоговую оценку. Это одновременно:

- требование прикладной задачи (контроль нарушений, нужна доказуемость);
- наше отличие от типового «вернули топ-10 по косинусу»;
- хорошая опора на питче — показывать пару кадров с подсвеченными приметами убедительнее,
  чем показывать mAP.

## Чего сознательно **не** делаем

- Не пишем свой ANN-индекс — берём FAISS/Qdrant.
- Не пишем свой фреймворк обучения Re-ID — берём готовый.
- Не строим распределённую систему: на хакатоне это съест время и не добавит баллов.
- Rust — только если станет узким местом по латентности **и** останется время.
  В заявке он назван, но это не повод тратить на него дни: заявка не обязательство.
